# Mine Papers Online

[English](README.md) | **Русский**

Рамка для Minecraft со своими картинками: файл с компьютера, слайдшоу из папки, ссылка на картинку или публичная папка Яндекс Диска или Google Диска. Картинки с компьютера выкладываются на сервер, поэтому их видят все игроки.

| Minecraft | Загрузчик |
| --- | --- |
| 1.7.10 | Forge |
| 1.12.2 | Forge |
| 1.20.1 | Forge, Fabric |
| 1.21.1 | NeoForge, Fabric |
| 26.1.2, 26.2, 26.3 | Forge, NeoForge |

Для Fabric нужен Fabric API.

## Как пользоваться

Рамка крафтится из ванильной рамки и картины. ПКМ по висящей картине открывает настройки: источник, размер, материал рамки и холста, свечение, цвета, заголовок. Настройки можно скопировать в JSON и вставить в другую картину, даже в другой версии игры.

## Настройки

`config/minepapers.json`:

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `stackMaterials` | `true` | Стопка картин в руке меняет материалы целиком. |
| `hideNsfw` | `false` | Скрывать картины с пометкой 18+. |
| `titleNeedsSneak` | `true` | Показывать заголовок только с зажатым Shift. |
| `disassembleSigned` | `false` | Разрешить разбирать подписанные картины в крафте. |
| `disassembleLocked` | `false` | Разрешить разбирать заприваченные картины в крафте. |
| `maxImageMb` | `16` | Максимальный вес картинки, выкладываемой на сервер, в МБ (от 1 до 256). GIF тяжелее лимита теряет анимацию. |

## Сборка

Нужен JDK 25. Запустить `build.bat` (`build.bat test` заодно прогоняет игровые тесты). Jar-файлы лежат в `build/libs` каждой версии.
